
# 🏦 Banking Transaction Analysis Dashboard

## 📌 Project Overview

An interactive Power BI dashboard developed to analyze **banking transactions, customer activity, transaction patterns and financial performance** through key business KPIs.

The dashboard helps management monitor transaction volume, transaction value, customer activity, account performance and regional trends to support data-driven business decisions.

## 🎯 Business Objectives

* Monitor total transaction volume and transaction value
* Analyze transaction performance by region and branch
* Track customer transaction activity
* Identify high-value transaction patterns
* Analyze transaction types and payment channels
* Monitor account and customer performance
* Identify trends and unusual transaction patterns
* Support data-driven banking decisions

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Excel
* Data Modeling
* Star Schema
* KPI & Dashboard Design

## 📊 Key KPIs

* Total Transaction Amount
* Total Transactions
* Total Customers
* Average Transaction Value
* Deposit Amount
* Withdrawal Amount
* Transfer Amount
* Transaction Success Rate
* Active Customers
* Regional Transaction %
