# 🏦 Banking Transaction Analysis Dashboard

## 📊 Project Overview

The **Banking Transaction Analysis Dashboard** is an interactive Power BI business intelligence solution designed to analyze banking transactions, customer segments, transaction performance, fees, taxes, and customer demographics.

The dashboard transforms banking transaction data into actionable business insights through interactive KPIs, charts, slicers, navigation, dynamic metrics, and detailed transaction-level analysis.

The goal of this project is to provide a centralized analytical view of banking transactions and help users monitor financial activity, transaction trends, customer behavior, and transaction performance.

---

## 🎯 Business Objectives

The dashboard is designed to answer key banking business questions:

- What is the total transaction amount?
- How many transactions are processed?
- What is the average transaction value?
- How much revenue is generated through transaction fees?
- What is the total tax associated with transactions?
- How is transaction amount changing over time?
- Which transaction statuses contribute the highest transaction amount?
- Which customer segments generate the highest transaction value?
- Which states contribute the highest transaction amount?
- Which transaction types are most frequently used?
- How does transaction activity differ by gender?
- How is banking performance changing compared with the previous year?
- What are the details of individual transactions?

## 📈 Key KPIs

The dashboard tracks important banking performance indicators such as:

| KPI | Purpose |
|---|---|
| Total Amount | Monitor total transaction value |
| Total Transactions | Monitor transaction volume |
| Average Transaction Value | Monitor average transaction size |
| Total Fees | Monitor fee generation |
| Total Tax | Monitor transaction-related tax |
| Transaction Success % | Monitor successful transactions |
| Failed Transactions | Monitor transaction failures |
| Pending Transactions | Monitor pending transactions |
